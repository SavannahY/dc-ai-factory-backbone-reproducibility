# References Folder

This folder collects the references used by the Nature Communications manuscript
draft `submission_package/Direct_current_subtransmission_backbones_for_grid_stable_AI_factories_NComms_v3.md`.

Contents:

- `references.md`: human-readable numbered reference list grouped by topic.
- `references.csv`: structured reference table with DOI, URL, manuscript role and local-copy status.
- `references.bib`: BibTeX entries for all numbered references.
- `download_manifest.csv`: files attempted/downloaded into `downloads/`.
- `downloads/`: public/open reference files and author-provided review copies saved locally.

Not every reference should be redistributed as a local PDF. IEEE, IEC and CIGRE
items may require subscription, standards purchase or member access; when those
files are present here, treat them as local author-review copies unless the
source license allows public redistribution.
